# Bash Infrastructure Toolkit

Набор модульных bash-утилит для автоматизации задач системного администрирования Linux (RHEL/РЕД ОС совместимый).

## Возможности

- **user_manager.sh** - массовое создание/удаление пользователей из CSV с генерацией временных паролей
- **preflight_check.sh** - pre-flight проверки окружения перед деплоем сервисов
- **log_analyzer.sh** - анализ системных метрик с расчётом средних значений и порогов
- **secure_cli.sh** - интерактивный CLI с безопасным вводом (скрытый пароль, таймауты)

## Особенности

- Модульная архитектура (переиспользуемые библиотеки в `src/lib/`)
- Централизованное логирование с уровнями (INFO/WARN/ERROR)
- Обработка ошибок через `set -euo pipefail` и `trap`
- Цветной вывод для удобства работы в терминале
- Идемпотентность операций
- Совместимость с POSIX-совместимыми дистрибутивами

## Требования

- Bash 4.0+
- Linux (тестировалось на РЕД ОС, RHEL 8+)
- Утилиты: `bc`, `getent`, `openssl`
